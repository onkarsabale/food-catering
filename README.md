# 🍽️ Food Catering Website

A responsive and modern **Food Catering Website** developed using **HTML, CSS, and JavaScript**. This project is focused on creating an attractive user interface for a catering business, allowing users to explore services, browse menus, and contact the catering company.

---

## 📌 Project Overview

This is a **frontend-focused web project** designed for a food catering service. It demonstrates responsive web design, clean layouts, interactive elements, and user-friendly navigation.

The website can be used as a college mini-project, portfolio project, or a base template for developing a complete catering management system.

---

## ✨ Features

- Responsive homepage
- Modern and attractive UI
- Navigation menu
- Catering service information
- Food menu section
- About Us section
- Contact section
- Smooth scrolling
- Interactive buttons
- Mobile-friendly layout
- Clean and simple design

## 🚀 How to Run the Project

1. Download or clone the project.
2. Extract the ZIP file (if downloaded).
3. Open the project folder.
4. Double-click **index.html**

The website will open in your default browser.
